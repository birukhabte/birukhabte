## 🧠 Engineering Philosophy

I believe great software is **built to evolve**. My technical decisions are guided by:

| Principle | Application |
|-----------|-------------|
| **Clean Architecture** | Business logic independent of frameworks, enabling easy technology swaps |
| **Scalability First** | Design for 10x growth from day one—horizontal scaling, stateless services, idempotent operations |
| **Observability by Default** | Every service emits structured logs, metrics, and traces—no debugging in production blind |
| **Test as Documentation** | Tests that read like specifications; integration tests that mirror real user flows |
| **Infrastructure as Code** | Every environment defined in code—reproducible, auditable, reviewable |

**Quote I live by:**
> *"Make it work, make it right, make it fast."* — but always with the understanding that "right" includes performance from the start.

## 🌍 Current Focus

I'm currently building **[CloudLog](https://github.com/alexchen/cloudlog)** — an open‑source logging platform optimized for serverless environments.

**Why this matters:** Existing logging solutions weren't built for the ephemeral nature of serverless functions. CloudLog provides:
- Automatic log aggregation across 1000+ concurrent function invocations
- Sub‑second search latency without indexing costs
- Zero‑configuration OpenTelemetry integration

**Learning:** Deep‑diving into **Rust** for performance‑critical components while maintaining the core in Go for ergonomics.
